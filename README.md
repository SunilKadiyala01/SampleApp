
# SampleApp

A React Native mobile application project built using React Native CLI.

## Getting Started

### Prerequisites

Make sure you have configured your development environment by following the [React Native Environment Setup](https://reactnative.dev/docs/set-up-your-environment) guide.

### 1. Start Metro

From the project root, run:

```bash
npm start
```

### 2. Run the Android App

Open another terminal in the project root and run:

```bash
npm run android
```

You can run the app on an Android emulator or a connected Android device.

### 3. Modify the App

Open `App.tsx` and make your changes. React Native Fast Refresh will update the app when you save your changes.
